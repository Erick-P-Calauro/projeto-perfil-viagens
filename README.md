# Projeto Prático : Perfil de Viagens

Este repositório contém a resolução obtida no projeto prático do módulo "Layouts Avançados com CSS" da Formação Full-Stack da Rocketseat. 

Veja o resultado em : https://erick-p-calauro.github.io/projeto-perfil-viagens

## Quais conhecimentos foram demandados ?

O projeto foi realizado utilizando exclusivamente HTML e CSS. Como o nome do módulo sugere, o objetivo dessa atividade era praticar conceitos mais avançados nos tópicos de layout em CSS, principalmente layouts flexbox, pseudo-classes, pseudo-elements, e utilização de variáveis.

## Créditos

O design do desafio foi fornecido como material pela Rocketseat.
A implementação é de minha autoria, desenvolvida com apoio das aulas contidas no módulo indicado.
